# Caffio Privacy Policy

The Caffio privacy policy has moved to the Moccoa Works website:

**https://moccoaworks.com/privacy/**

The version that used to be in this file (dated 2026-06-11) is outdated and no longer
accurate. In particular, it said that no third-party servers were used. Caffio now uses
Supabase for reviews, taste preferences, and other community features. Please refer to
the page above for the current policy.
