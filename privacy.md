# Caffio Privacy Policy

Effective Date: 2026-06-11

## English

Caffio ("we", "our", "the app") handles the following data:

### Data Collected
- Photo and image data (coffee package photography)
- Text information entered by the user (log content)
- Text extracted by OCR

### Data Storage
- Local: stored only on the user's device
- iCloud: when sync is enabled with Plus/Pro subscription, data is stored in the user's personal iCloud account
- Third-party servers: not used

### Data Sharing
- We do not share data with third parties.

### Subscriptions
- Handled via Apple's standard StoreKit. Subject to Apple's privacy policy.

### User Rights
- Deleting the app removes local data
- iCloud sync data can be removed from iOS Settings → Apple ID → iCloud → Manage Storage

### Contact
- Email: mocotomo.vdd@gmail.com

## 日本語

Caffio（以下「本アプリ」）は、以下のデータを取り扱います。

### 収集するデータ
- 写真・画像データ（コーヒーパッケージ撮影）
- ユーザーが入力したテキスト情報（記録内容）
- OCR で抽出されたテキスト

### データの保存先
- ローカル: デバイス内のみ
- iCloud: Plus/Pro プラン契約者で同期 ON の場合、ユーザー個人の iCloud アカウントへ保存
- 第三者サーバー: 利用しません

### データの共有
- 第三者と共有することはありません。

### サブスクリプション
- StoreKit 経由の Apple 標準処理を利用。Apple のプライバシーポリシーに準拠。

### ユーザーの権利
- アプリ削除でローカルデータ消去
- iCloud 同期データは iOS の設定 → Apple ID → iCloud → ストレージから削除可
